# Configured OPTION UNDERLYINGS (app.engine.option-tickers-path, default
# classpath:option-tickers.txt). Loaded once by OptionUniverseLoader.
#
# This file lists UNDERLYING STOCK symbols (NOT OCC codes). For each underlying the
# options service pulls the current spot price and GENERATES the nearest
# `app.options.strikes-per-side` ITM + the same number of OTM strikes for each
# configured side (CALL/PUT) at the chosen expiry, builds the OCC symbols, and loads
# option bars for them.
#
# Example: with strikes-per-side=5 and sides=[CALL,PUT], "AAPL" expands to
# 5 ITM + 5 OTM = 10 CALL strikes and 10 PUT strikes = 20 contracts.
#
# FORMAT (one underlying per line):
#   SYMBOL                 → use the default strike increment (app.options.default-strike-increment)
#   SYMBOL,<increment>     → override the strike spacing for THIS symbol only
#
# The optional increment lives here (not in application.yml) so each symbol is
# configured in exactly one place. '#' comments and blank lines are ignored;
# symbols are upper-cased and de-duplicated.
#
# NOTE: Webull's v3 API has no option-chain endpoint, so strikes are generated from
# the increment. A generated strike that isn't actually listed just returns no bars
# (logged per-contract) — it never fails the whole pull. If a symbol's strikes keep
# coming back empty, its increment here is probably wrong.
#
# Expiry is driven by app.options.dte (e.g. 0DTE = today, 1DTE = today+1, ...).
